# 月见 · 个人收支账本

一个无需注册、无需安装前端依赖的本地收支网站。普通记账离线可用，DeepSeek 分析按需调用。

## 公开源码与个人数据

本仓库只包含程序、文档和合成测试数据；界面的示例账本由代码生成，不代表任何人的真实收支。每位使用者的真实账本保存在自己的浏览器中，API Key 由使用者在本机单独配置。公开源码不会同步本地账本或 API Key。

`.gitignore` 已排除本机密钥配置、常见账单文件和月见导出的备份。自行保存或改名的备份仍可能包含个人信息，请勿提交；在 GitHub 反馈问题时也请先删除真实姓名、交易号、账单内容和密钥。

## 打开方式

下载源码并解压，或运行 `git clone https://github.com/wwhNLP/moonledger.git`，然后进入项目文件夹。

双击 `启动月见.command`，随后访问 http://127.0.0.1:4173 。需要 Python 3.9 或更新版本；关闭启动窗口即停止本地服务。

也可在本目录运行 `python3 server.py`。请始终使用相同浏览器和固定网址；不同网址、端口或浏览器的数据互相独立。建议使用新版 Chrome、Edge 或 Safari，保存需要浏览器的 Web Locks 支持。AI 功能需要此本地服务，不要直接打开 HTML 文件或改用普通静态服务器。

## 使用

- 首次打开是独立的示例账本，点击「开始我的账本」开始记录真实收支。
- 记账支持收入、支出、日期、分类和备注，可编辑、删除、按月查询。
- 概览展示月度结余、收入、支出、结余率、连续六个月趋势和支出分类。
- 月预算按月独立设置，只计支出；填写 0 取消预算。
- 「数据与备份」可以导出完整 JSON 备份和当月 CSV，或导入 CSV、恢复 JSON。
- CSV 表头：`日期,类型,分类,金额,备注`。日期为 `YYYY-MM-DD`；类型为 `收入` 或 `支出`；金额为正数且最多两位小数；分类需与网站一致。
- JSON 恢复可以合并或替换。合并自动跳过相同编号或内容的重复记录，并保留已有设置；替换需要再次确认。新备份版本为 2，包含固定模板、分类预算与重复确认状态，仍能读取版本 1 的备份。

原始账本存在当前浏览器 localStorage。清除浏览器数据会删除本地账本，请定期导出备份。网站不直接连接银行、支付宝或微信账户，使用你从支付应用导出的文件。如果内嵌浏览器阻止下载，可展开导出窗口中的备用文本，复制并保存为对应文件。

## 新增的日常功能

- **智能导入**：从首页「导入账单」、工具箱或数据与备份进入。支持微信／支付宝个人对账 CSV、XLSX 和月见 CSV；CSV 自动识别 UTF-8 / GBK。文件头说明行会自动跳过，列顺序无需调整。先预览，可改性质、分类、金额和关联原单；交易未完成、退款状态、内部转账、未知状态和疑似重复默认不选，核对后手动勾选。相同平台交易事件无法重复写入，修改账单性质也不会改变其原始去重身份。
- **固定账单**：在工具箱创建每月模板，可设置金额、分类、日期、开始／结束月份和暂停。每月生成待确认项，手动确认才入账。31 日遇到短月取该月最后一天；同一模板同月只入账一次。删除模板不会删除历史记录，删除对应已入账记录后该月份可重新确认。
- **退款、报销与内部转账**：「记一笔」与编辑窗口新增账单性质。退款／报销可关联原支出，支持部分及多次到账；关联累计金额不超过原支出，到账日期不早于原支出。普通支出可标记待报销，在工具箱查看未收金额。原支出不在账本中时可暂不关联，仍需自行核对。自己账户间转账不计收支；付给房东、朋友的实际消费不应标记内部转账。
- **分类预算**：月度预算页面设置总额度和八类支出额度，可沿用上月。两者分别提醒，分类合计不自动修改总预算；达到 80% 提示接近额度，超过后显示超支。每日额度包含今天，历史月份不计算未来每日额度。
- **疑似重复检查**：工具箱中检查整个当前账本的同日、同额、同收支性质记录。保留真实的两笔后不再提示；修改记录后重新检查。最多展示最近 100 组，处理后会显示后续组。删除操作仍需确认；有已关联退款／报销的原支出需先处理其关联记录。
- **消费日历**：点击某天查看明细，可直接把新账单记在选中日期。颜色表示当日实际消费；收入和收回款项另列，转账只出现在明细。
- **年度总览**：选择年份查看收入、净支出、结余、各月金额、年度分类及与上一年的变化，点击月份转到账单明细。全年合计包括已记录的未来日期；当前年的月均只统计截至本月的月份，其他年份按 12 个月计算，均包含无记录月份。

统计统一按发生月份：原消费计支出，退款／报销在**实际到账月份冲减支出，不作为收入**。因此某月只有退款到账时，净支出可能为负，结余为正。环图只绘制净额为正的分类，负分类冲减单独注明；年度图用斜纹标注负支出。待报销不提前减少支出。AI 预览和分类预算使用同一口径。

XLSX 通过当前本机服务在内存中解析，不写入文件、不执行公式、不发送至第三方。支持单个 10 MB 以内、最多 10 个工作表的未加密文件；多个交易工作表需分别导出再导入。ZIP 请先解压，PDF 证明版及旧 XLS 需转成 CSV / XLSX。日期或金额有误的行会显示原因，不会静默当作零元。支付平台格式可能变化，无法识别时可用月见 CSV 模板。

JSON 是完整备份格式。CSV 在需要时带上性质、关联编号、来源和模板信息，但不包含预算与模板配置；导入单月退款 CSV 时，原支出需已存在于账本，或在预览中清除关联后单独记账。

## AI 财务助手

在侧栏「AI 设置」填写自己的 DeepSeek API Key，保存后即可使用。默认模型为 `deepseek-flash`，可按自己账户可用的模型修改。Key 也可通过环境变量 `DEEPSEEK_API_KEY` 配置，模型对应 `DEEPSEEK_MODEL`；页面保存的配置优先。

- **月度复盘**：显示本地计算的精确收入、支出、结余及分类依据，点击发送后由 AI 解读。
- **问问账本**：先在本地识别月份、分类、对比、平均、排行或预算等查询条件，预览范围后再发送。相对月份以页面选择的月份为基准。支持示例「最近三个月餐饮平均花多少」「去掉房租，这个月花了多少」。房租仅通过本地备注中的关键词排除，依赖记账完整性；商户、人物、金额门槛等复杂查询会要求改写，避免误答。
- **一句话记账**：在「记一笔」内打开，输入如「昨天午饭38元，打车26元，今天收到工资18000元」。本地识别金额与日期，生成可编辑草稿；可选 AI 辅助分类。核对后才入账，未配置 Key 也能使用。退款、报销、转账需要自行确认收支类型。

## 脱敏与存储

- 不会自动发送数据；仅点击发送分析或 AI 辅助分类才访问 DeepSeek 官方 API，可能产生账户 API 费用。没有 Key 时会提示设置，不会显示伪造的 AI 结果。
- 月度复盘与问答只发送匿名月份编号、标准分类、汇总金额（分）、预算、笔数和计算结果。**汇总金额仍属于财务信息**；每次可展开「查看实际发送的脱敏内容」核对。不会发送交易明细、绝对日期、姓名、账户、商户、备注或提问原文。
- 一句话记账的 AI 请求更少：仅匿名编号和固定分类提示，不发送金额、日期或输入原文。
- 浏览器和本地服务分别校验白名单；本地服务只监听 `127.0.0.1`，校验来源及会话令牌，固定请求 DeepSeek 官方地址，不接受任意转发地址。
- Key 保存在本机 `.local/deepseek.json`（文件权限 `0600`、目录 `0700`），未加密；不会放入浏览器存储、账本备份、网页源码或响应中。该目录已加入 `.gitignore`。可在 AI 设置中删除本机保存的 Key；环境变量需另行移除。
- AI 结果只在当前页面内存中缓存；账本、月份或模型变化会重新匹配。数字由本地程序计算，AI 只解释对应依据，不会修改账单。
- 多页面保存通过浏览器锁与合并处理；对同一账单的冲突修改会提示，不会静默覆盖。

## 检查

```sh
node --test tests/*.test.cjs
python3 -B -m unittest discover -s tests -p 'test_*.py'
```

测试覆盖账本计算、跨月回款、关联金额上限、模板日期与防重复、分类预算、年度汇总、支付账单识别与来源去重、XLSX 日期／长编号／公式／大小限制、备份往返、脱敏白名单、并发合并、密钥权限、请求来源保护和模拟 DeepSeek 响应。模拟测试不使用真实 Key，也不产生 API 费用；真实模型效果需配置自己的 Key 后验证。

源码在 `dist`，使用原生 HTML/CSS/JavaScript，无安装和构建步骤。
